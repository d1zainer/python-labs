# Лабораторная работа 3.1 — ML API на FastAPI

## Смысл задачи

Реализация REST API для модели машинного обучения.

Модель решает задачу **бинарной классификации** — имитирует банковский скоринг: по данным о человеке (возраст, доход, город) предсказывает, одобрить заявку или нет.

Внутри пайплайна:
- `OneHotEncoder` — кодирует город в числа
- `RandomForestClassifier` — принимает решение

## Запуск

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Обучить модель и сохранить

```bash
python case/3_1/train_and_save.py
```

### 3. Запустить сервер

```bash
uvicorn case.3_1.api:app --reload
```

Сервер запустится на `http://127.0.0.1:8000`

## Тестирование

Открыть в браузере Swagger UI:

```
http://127.0.0.1:8000/docs
```

Нажать `/predict` → **Try it out** → ввести данные → **Execute**.

## Пример запроса

**Входные данные:**
```json
{
  "age": 40,
  "income": 80000,
  "city": "SPb"
}
```

**Ответ:**
```json
{
  "prediction": 1,
  "probability": 0.84
}
```

- `prediction` — решение: `1` одобрено, `0` отказ
- `probability` — уверенность модели от 0 до 1
